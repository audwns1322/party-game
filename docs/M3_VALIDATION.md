## 운영 및 검증 한계
- 요청 시 기한 검증 방식(PRD 허용). DB 서버 시간만 전환을 결정한다. 인증 snapshot/heartbeat가 방 잠금 안에서 한 번 전환하고 공개 version만 Broadcast.
- 접속자가 없으면 다음 인증 요청에서 만료 상태를 확정한다. 토론 중 클라이언트는 2초 간격 snapshot을 재조회하고, 시간 0 화면은 서버 응답을 기다린다.
- 실제 60초를 기다린 원격 테스트 방은 종료·삭제, UUID 기준 잔여 0 확인. 별도 UI 테스트 방도 종료·삭제했다. 사용자 기존 방은 변경하지 않았다.
- 모바일 실기기 레이아웃·다중 기기 인수, 장시간 장애/복귀 조합은 미완료. 연결 단절 자동 정지/방장 위임은 M6 범위.
- 사용자 요청으로 M3 main 병합 승인(2026-10-24). 실제 병합·배포 상태는 PR #3 참조. 실기기 인수 제한은 유지하며 M4 미착수.

## 토론 조기 종료 보완 — 2026-10-24

사용자 요청으로 방장은 제한 시간이 남아 있어도 `남은 시간 건너뛰기`를 눌러 토론을 종료할 수 있다. 4초 내 두 번째 클릭으로 확인하며, UI는 명시적 JSON boolean `skip_timer:true`를 보낸다. 서버는 기존 방장·참가자·단계·version·request_id 검사를 그대로 유지한다. 플래그가 없거나 문자열인 요청은 기존대로 기한 전 거부한다. 일시 정지 상태에서는 사용할 수 없으며, 먼저 재개해야 한다.

- 신규 SQL/핸들러 회귀: 변경 전 409 실패 재현 → 변경 후 통과. 비방장 거부, 문자열 플래그 거부, 조기 종료 시 deadline 제거, 동일 요청 재시도/이전 단계 거부 확인.
- 로컬 단위 20 + SQL/핸들러 49 = 69개, 린트·타입 포함 빌드 통과. 적용 migration `20261024142118_discussion_skip`. 기존 적용 migration 파일은 수정하지 않았다.

- 개발 Supabase 원격 검사 24개 통과: 기존 실제 60초 자동 만료에 더해 120초 토론을 기한 전 종료, 비방장 거부, 동시 동일 요청 1회 반영 확인. 원격 테스트 방 종료·정리.
- 내장 브라우저에서 3분 토론 중 167초가 남은 상태로 첫 클릭 시 확인 문구만 표시, 두 번째 클릭 후 VOTE_1 진입을 확인. 테스트 방 종료·정리. 모바일 실기기 인수는 이번에도 미실행.
