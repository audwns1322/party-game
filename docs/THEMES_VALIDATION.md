# 테마·혼선 라이어 검증 — 2026-10-26

## 범위
- 음식·동물·생활용품·장소·취미·자연·운동·크로스핏·여행 9개 공개 테마, 각 15개로 총 135개 기본 단어.
- 기본 라이어는 테마만, 혼선 라이어는 같은 테마의 다른 단어 제공. 이지는 유사 단어 묶음 안, 하드는 다른 묶음에서 미리 정한 조합. 난이도는 라이어 기준.
- 방장만 테마·게임 방식·난이도를 설정하고 한 판의 config를 고정. 각자 본인의 단어만 서버 DTO로 받고 단어는 누르는 동안 표시한다.
- 직접 입력은 방장 테마 1~30자 저장 후 기존처럼 단어 하나만 제출. 혼선 모드와의 조합은 서버도 거부. 시민 후보 선택·라이어 후보 제외 유지.

## 제한
- 유사성과 실제 난이도는 의미 판정 AI가 아닌 큐레이션이다. 실전 피드백에 따라 조합을 조정한다. 공개 테마 안의 단어 자체나 모든 조합을 브라우저에 내려주지 않는다.
- 모바일 실기기·3대 인수는 이번에도 미실행. 기존 보류 2건 유지. M4 투표·M5 결과는 이번 범위가 아니며 기존 VOTE_1 안내까지 제공한다.
- 기존 클라이언트는 새 UI를 받도록 한 번 새로고침한다. 이미 진행 중인 판의 config는 바꾸지 않는다. 이전 판의 테마 정보가 없는 경우 기존 표시로 동작한다.
- 내장 브라우저에서 테마 9개 선택지, 크로스핏 안내, 혼선 라이어·하드 설정을 확인. 직접 입력 전환 시 혼선 설정을 숨기고 기본 라이어로 바뀌며, 테마 미저장 안내→방장 테마 저장 후 참가 인원 안내 복귀를 확인했다. 모바일 실기기 검증은 아님.
- 적용 후 advisor는 WARN/ERROR 없음. 보안 INFO 10개(의도한 private RLS deny-all), 성능 INFO 1개(기존 미사용 인덱스).
